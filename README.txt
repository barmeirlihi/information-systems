קבצים ראשיים

- main.py - הקובץ הראשי של האפליקציה, מכיל את כל ה-routes וה-logic  הראשי
- data.py - חיבור לבסיס הנתונים MySQL ופונקציות לביצוע שאילתות SQL
- users.py - ניהול משתמשים רשומים (הרשמה, התחברות, קריאת פרטים)
- guest.py - ניהול משתמשים אורחים (הזמנה ללא הרשמה)
- flights.py - ניהול טיסות, מטוסים, מושבים, צוותים ונתיבים
- order.py - ניהול הזמנות וכרטיסים
- reports.py - יצירת דוחות וגרפים למנהלים

תיקיות

- templates/ - קבצי HTML דפי התחברות, הזמנות, ניהול טיסות, דוחות וכו'
- static/ - קבצים עיצוביים:
    - style.css - עיצוב האפליקציה
    - images/ - תמונות ולוגו
    - charts/ - גרפים שנוצרים עבור הדוחות – מתעדכנים בהרצה הרלוונטית
- flask_session_data/ - נתוני session של המשתמשים (נוצר אוטומטית)
